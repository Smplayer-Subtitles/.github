# SMPlayer - Play a Video File You Already Have

## Core SMPlayer Features

- **Local Playback:** Open a file or a folder of files you may watch. The player does not supply the movie.
- **Remembered Position:** It can resume where you stopped in a file you were already watching.
- **Audio and Subtitles:** Pick a track that is already inside the file, or a subtitle file you have beside it.
- **A Normal Window:** Pause, seek, and close. A file that will not open is incomplete or in a form this player cannot read, not a lock to remove.

---

## About SMPlayer

SMPlayer is a front end for playing media you already have on disk. A recording you made, a file a publisher gave you, or an export from an editor you ran are the usual sources. It does not search pirate indexes, and it does not strip protection from a disc. If the file is not yours to play, a better player will not change that.

Install the player, then open one known file. If that file is silent, check the audio track and the volume before you reinstall anything. Subtitles that do not match the cut will drift. Use a subtitle that belongs to this file, not a random download named like the movie.

Close the player when you leave a shared PC if the recent-files list would show titles you do not want on screen for the next person.

## Tool Benefits

- **A File You Chose:** Playback starts from your folder, not from a catalog.
- **Resume:** You can continue a long file you paused.
- **Tracks That Are Already There:** Audio and subtitles are selections, not a download step.

## Getting Started with SMPlayer

Prerequisites: One video or audio file you may play, stored locally.

1. **Open That File:** Use Open, not a search for a title on the web.
2. **Check Picture and Sound:** Pick the audio track if there is more than one.
3. **Pause and Resume:** Close and reopen if you want to see whether the position was kept.
4. **Leave It:** Do not add sites or lists that offer films you do not own.
